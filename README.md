### ✨ 功能特性

- 📦 **批量压缩**｜支持添加多张图片，或拖入文件夹批量导入
- 🖼️ **多种输入格式**｜支持 JPG / PNG / GIF / SVG
- 🎚️ **两种压缩模式**｜按压缩强度调整，或设置目标文件大小
- 📐 **尺寸调整**｜支持保持原始宽高比，也可独立设置宽度和高度
- 🔄 **格式转换**｜保留原格式，或转换为 WebP、PNG、JQC
- 📁 **灵活保存**｜保存到原文件夹、自定义文件夹，或覆盖原文件
- 🏷️ **自定义文件名后缀**｜方便区分原图和处理后的图片
- 📊 **处理状态展示**｜查看等待、处理中、完成、无法压缩和错误状态，以及压缩前后的大小与节省比例
- ⚡ **快捷操作**｜支持再次压缩、清空列表，以及在 Finder 中定位文件
- 💡 **备注**｜目标大小模式会尽量接近所选大小，实际结果受图片内容、格式及尺寸影响

### 🚀 使用方法

1. **设置压缩参数**：设置压缩方式、尺寸、输出格式及保存位置
2. **添加图片**：拖入图片，或点击「添加图片」选择文件
3. **查看处理结果**：在列表中查看处理状态与压缩前后大小；调整参数后，可点击「再次压缩」
